Fonts for the PDFs (`apps/sheet_pdf.py`), so a downloaded bill or report is set in the same
type as the sheet the browser prints.

- Archivo (Regular, SemiBold, Bold) — SIL Open Font License, Omnibus-Type.
- IBM Plex Mono (Regular) — SIL Open Font License, IBM.
- Noto Sans Bengali (Regular, Bold) — SIL Open Font License, Google. Used for the taka
  sign and Bengali letters, which Archivo does not carry.
